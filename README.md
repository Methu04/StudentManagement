# 🎓 Student Management System – Java Console App

This is a **Java-based Student Management System** built as part of my Software Development II coursework. The system allows users to register, search, delete, and manage student records via a menu-driven CLI interface.

---

## 📌 Features

- 🧑‍🎓 Register and delete students by ID  
- 📝 Assign names and module marks  
- 🔍 Search students and view sorted lists  
- 💾 Save/load student data to/from text files  
- 📊 Generate performance summaries and reports  
- 📋 Built-in validation and error handling

---

## 🛠 Technologies Used

- ![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=java&logoColor=white)
- IntelliJ
- File I/O (FileReader, FileWriter)
- Object-Oriented Programming (Classes, Encapsulation)
- CLI-based Interaction

---

## 🧾 Project Structure

- `StudentManagementMenu.java`: Main CLI menu logic and operations  
- `Student.java`: Student class with name, ID, and module marks  
- `Module.java`: Simple class for managing individual module marks  
- File: `StudentDetails.txt` used for persistence

---

## ✅ Key Functionalities

- View available seats  
- Validate unique student IDs  
- Sort student names alphabetically  
- Generate reports sorted by average mark  
- Submenu for additional operations (name, marks, reports)

---

## 🔧 How to Run

1. Clone the repo  
2. Open the `.java` files in IntelliJ or NetBeans  
3. Run `StudentManagementMenu.java`  
4. Follow the console instructions
